## 👨‍💻 Sobre mí

Profesional en transición hacia **Ciberseguridad**, con experiencia previa en entornos administrativos y desarrollo de software.

### Burp Suite Proxy Lab

Laboratorio con dos máquinas virtuales independientes para configurar y analizar un proxy de interceptación con Burp Suite.

Incluye:

- Configuración de red virtual
- Proxy HTTP/HTTPS
- Instalación de CA
- Interceptación de tráfico
- HTTP History
- Modificación de requests
- Análisis de implicaciones defensivas

➡️ [Ver laboratorio](https://github.com/JORSIECHARTE/cybersecurity-labs/tree/main/burp-suite-proxy-lab)
